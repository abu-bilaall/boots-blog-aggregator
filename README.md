# Boots Blog Aggregator

A lightweight blog aggregator that pulls posts from multiple sources and presents them in a unified, searchable feed.

## Motivation
This project was built as part of a guided tutorial on [boot.dev](https://boot.dev). The tutorial’s exercises motivated the creation of a simple, extensible aggregator for personal blog feeds.

## Quick Start
```bash
# Clone the repo
git clone https://github.com/yourorg/boots-blog-aggregator.git
cd boots-blog-aggregator

# Install dependencies
pip install -r requirements.txt

# Run the server
python -m boots_blog_aggregator
```

## Usage
- Access the web UI at `http://localhost:8000`.
- Add or remove RSS/Atom feed URLs in `config.yaml`.
- Search posts by title, author, or tags using the built‑in search bar.
